# Motor Parking — Owner Trial Guide

## 1. Install it (do this first)
Open the link on the parking phone's browser (Chrome recommended), then
**Add to Home Screen**. Always open the app from that home-screen icon —
installed apps keep their data far safer than browser tabs.

## 2. Daily use
- **Park:** Operations → type the plate → Park. Tap the plate itself to fix a typo.
- **Paid:** tap the UNPAID badge when the customer pays (it turns green).
- **Checkout:** Out → Confirm checkout. Unpaid checkouts stay listed and can be
  **Settled later from History** (Action column) when the customer returns.
- **Operations header:** Collected = today's takings plus overnight holds
  still parked (shown as "incl. ₱X overnight"). It never resets at
  midnight while paid bikes are still on the lot.
- **History:** past stays grouped by day, with paid times and totals.
- **Analytics:** revenue, bikes, peak hour, and unpaid per Today / 7 days /
  This month / This year, plus the month calendar.

## 3. End of day (2 minutes, protects your records)
Settings → **Daily reports** → Download today's file. Keep the files somewhere
safe (email them to yourself weekly). If anything ever happens to the phone,
these files are the records.

## 4. Clearing data
Settings → Clear All Data asks twice, and a full backup downloads automatically
first. Never delete that backup file.

## 5. Updates
If the app says an update is available, close and reopen it to apply.
Check Settings → Storage for the version (v…) when reporting any issue.

## 6. Trial limits (by design, not bugs)
- One phone only. No accounts, no logins.
- All data lives on that phone. A factory reset without a backup or report
  files means the records are gone.
- If the app ever shows an error card, tap Reload. If a problem repeats,
  note the version from Settings and describe what you tapped.
