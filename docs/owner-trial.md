# Motor Parking — Owner Trial Guide

## 1. Install it (do this first)

1. Open the app link (sent to you) in the parking phone's browser —
   Chrome on Android, Safari on iPhone.
2. Add it to the Home Screen (Android: menu → Add to Home screen;
   iPhone: Share → Add to Home Screen).
3. From now on, always open the app from that home-screen icon.
   Installed apps keep your data far safer than browser tabs.

## 2. Daily use

1. **Park:** Operations → type the plate number → Park (or press Enter).
2. **Fix a typo:** tap the plate itself on its row, correct it, press Enter.
3. **Paid:** tap **Mark Paid** on the row when the customer pays
   (it turns green). Tap again to undo before checkout.
4. **Checkout:** tap **Check Out** on the row → **Confirm checkout**
   in the sheet that slides up.
5. **Search:** use the search box above the parked list to find a plate fast.
6. **Long queues:** when the list gets long, a faint ↑ button appears
   near the bottom — tap it to jump back to the top.
7. **Parking Fee:** Settings → type the new fee → Save. Old records keep
   the fee they started with; only new entries use the new fee.

## 3. Understanding the numbers

- **Operations header:** Parked (bikes on the lot) · Collected · Unpaid.
- **Collected = today's takings plus overnight holds still parked.**
  If paid bikes stay overnight, they stay in Collected past midnight
  (shown as "incl. ₱X overnight"). Bikes that already checked out
  leave this number — their money is counted in Analytics and reports.
- **A day runs 12:00 AM – 11:59 PM** (phone time). Every daily report
  prints this window at the top, so there is no guessing.

## 4. Unpaid and settle-later

- A bike can check out without paying. It stays listed as Unpaid.
- When the customer returns and pays, go to **History**, find the row,
  tap **Settle**. Same-day payments can be undone with **Undo**.
- History groups everything by day with paid times and totals.
  Use the search box and the All / Paid / Unpaid filter to find records.

## 5. Analytics

- Tabs: **Today / This week / This month / This year.**
  This week means Monday–Sunday of the current week.
- Cards: revenue · entries · peak hour · unpaid.
- The month calendar shows each day's revenue and entries.
  ★ marks the best day, ● marks days with unsettled payments.

## 6. Reports (2 minutes at end of day)

1. Settings → **Daily reports**.
2. Pick a format: **CSV** (opens in Excel/Sheets, best for records),
   **HTML** (nicely readable, best for sending), **TXT** (plain and small).
3. Tap **Download** on any day — today works anytime, no need to wait.
4. Each file shows its coverage window (12:00 AM – 11:59 PM) and the
   actual activity span (first entry → last checkout). Files for today
   say "Ongoing snapshot"; past days say "Daily report".
5. If there are more than 3 days, tap **Show all** to see the full list.
6. Email the files to yourself weekly. If anything ever happens to the
   phone, these files are the records.

## 7. Backups and safety (important)

- **Export Backup** (Settings → Data & storage) downloads a full copy
  of everything. Do this weekly and keep the file somewhere safe.
- Watch the **Last backup** line: it turns amber when your backup is
  more than 7 days old or was never made.
- **Import Backup replaces ALL data on the phone** with the file's
  contents. Only use it to restore, never to combine two phones.
- **Clear All Data** asks twice and downloads a full backup
  automatically first. Never delete that backup file.
- All data lives on this phone only. No accounts, no cloud.
  A factory reset or erased browser data without a backup or report
  files means the records are gone.

## 8. Updates and problems

- Updates install automatically — just close and reopen the app.
- If a red message appears, it goes away on its own after a few
  seconds (or tap it to dismiss early).
- If the app ever shows an error card, tap Reload. If a problem
  repeats, note the version (Settings → Data & storage, the v…
  line) and describe what you tapped.
